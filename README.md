# 坦克大战 (Tank Battle)

一个用原生 **HTML + Canvas + JavaScript** 编写的经典《坦克大战》网页游戏。单文件实现，零依赖，打开即玩。

![Tank Battle](index.html)

## ✨ 功能特性

- 🎮 经典玩法：操控坦克移动、发射子弹、击毁砖墙与钢墙
- 🧱 多种地形：
  - 砖墙（可被子弹击毁）
  - 钢墙（不可摧毁，需升级火力）
  - 树林（坦克可藏身其中，子弹可穿过）
  - 水域（坦克不可通行，子弹可越过）
- 🦅 金鹰基地：保护底部基地，被击中即游戏结束
- 🤖 敌方 AI：敌人会向基地 / 玩家推进并随机开火
- ⭐ 道具系统：
  - ★ 升级火力（可击穿钢墙、增加同时发射的子弹数）
  - ◆ 护盾（短暂无敌）
  - ● 全屏炸弹（消灭场上所有敌人）
  - ♥ 加一条命
- 🗺️ 关卡系统：多张地图循环，逐关提升敌人速度与数量
- 🔊 音效、得分、生命、暂停 / 静音

## 🎮 操作方式

| 按键 | 作用 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动 |
| 空格 / `J` | 开火 |
| `P` | 暂停 / 继续 |
| `M` | 静音 / 取消静音 |
| 回车 / 点击屏幕 | 开始 / 重新开始 / 进入下一关 |

## 📜 游戏规则

- 每关需消灭全部 **20** 辆敌方坦克即可过关
- 保护底部中央的金鹰基地，基地被摧毁则游戏结束
- 初始 **3** 条命，命用完游戏结束
- 击毁敌方坦克 **+100** 分，通关额外 **+500** 分
